# Portfolio starter

This is a no-build personal portfolio site. Edit `index.html` to replace the placeholder name, title, bio, projects, email, and social links. `styles.css` controls the visual design.

## Publish with GitHub Pages

1. On GitHub, create a new public repository, for example `portfolio`.
2. Upload both files in this folder (`index.html` and `styles.css`) to the repository's top level.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select the `main` branch and the `/ (root)` folder, then save.
5. GitHub will display your public website address after it finishes publishing.

For a site address in the form `https://yourusername.github.io`, name the repository `yourusername.github.io`.
